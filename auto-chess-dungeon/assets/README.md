# Ресурсы MVP

Все игровые иконки в `icons/` созданы специально для этого прототипа в формате **SVG 96 × 96**. Они используют общую палитру тёмных контуров, кремового, золотого, кораллового и зелёного цветов.

- Комнаты: `goblin.svg`, `executioner.svg`, `poison.svg`, `spider.svg`, `spikes.svg`, `mimic.svg`.
- Герои: `knight.svg`, `rogue.svg`, `priest.svg`.
- Лорд и предметы: `lord.svg`, `sword.svg`, `shield.svg`.
- Варианты Владыки: `lord_knight.svg` — коронованный рыцарь в латах; `lord_necromancer.svg` — некромант с костяной маской и посохом; `lord_alchemist.svg` — алхимик в очках и с колбами. Все три иконки нарисованы для проекта в той же векторной палитре; нейтральный `lord.svg` сохранён.

Короткие звуковые эффекты синтезируются при запуске в `scripts/main.gd`, функция `_make_sound()`. Отдельные аудиофайлы не требуются. Интерфейс использует встроенный шрифт Godot.

Каменная архитектура, факелы, лестницы, трон и анимации фигур рисуются кодом в `scripts/dungeon_view.gd`. Изображение стартового меню также создано этим скриптом.

Портрет на троне берётся из выбранного архетипа в `scripts/lord_catalog.gd`, а знамёна окрашиваются в его цвет. Голубое кольцо со щитом обозначает поглощение урона, фиолетовая руна — подготовленное воскрешение, фиолетовые дуги после него — усиление вернувшегося защитника; золотая отметка показывает усиленные удары. Эти элементы только отображают состояние текущего защитника и не управляют боем.

Сторонние наборы графики, шрифтов и звуков для этой версии **не скачивались**. Для замены иконки достаточно отредактировать SVG или изменить поле `icon` соответствующего пресета в `data/rooms/`, `data/heroes/` или `data/items/`.
