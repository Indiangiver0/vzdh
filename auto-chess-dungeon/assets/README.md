# Ресурсы MVP

Для джема No Hero Returns: исходные SVG и код процедурной графики подготовлены с помощью OpenAI Codex по заданиям автора. Упоминание ручной записи SVG ниже описывает работу с векторным кодом, а не рисование человеком без ИИ. Звук синтезируется алгоритмом из кода, подготовленного с помощью Codex; отдельные модели генерации изображений, музыки и голоса не использовались.

Игровые иконки в `icons/` созданы специально для этого прототипа в формате **SVG 96 × 96**; интерфейсная иконка магазина `shop.svg` имеет размер **64 × 64**. Они используют общую палитру тёмных контуров, кремового, золотого, кораллового и зелёного цветов.

- Комнаты: `goblin.svg`, `executioner.svg`, `poison.svg`, `spider.svg`, `spikes.svg`, `mimic.svg`, `shackles.svg`, `silence.svg`, `rust.svg`, `guardian.svg`, `ogre.svg`, `war_hound.svg`, `wraith.svg`, `vampire.svg`, `ballista.svg`, `blade_floor.svg`.
- Герои: `knight.svg`, `rogue.svg`, `priest.svg`, `mage.svg`, `barbarian.svg`, `bard.svg`.
- Лорд и предметы: `lord.svg`, `sword.svg`, `shield.svg`.
- Интерфейс: `shop.svg` — сумка с монетой для кнопки магазина. Оригинальный SVG-код подготовлен Codex для проекта; сторонние изображения и шрифтовые символы не использованы.
- Варианты Владыки: `lord_knight.svg` — коронованный рыцарь в латах; `lord_necromancer.svg` — некромант с костяной маской и посохом; `lord_alchemist.svg` — алхимик в очках и с колбами. Все три иконки нарисованы для проекта в той же векторной палитре; нейтральный `lord.svg` сохранён.

Новые иконки комнат различаются по силуэту: скованные цепью наручники — оковы, перечёркнутая руна на колоколе — безмолвие, ржавый щит с руной — снижение брони, каменный страж со щитом — склеп. Чародей изображён в остроконечной шляпе с кристаллом на посохе, варвар — с топором, бард — с лютней. Иконки нарисованы вручную как исходный SVG для проекта; внешние изображения и файлы D&D не использованы.

Короткие звуковые эффекты синтезируются при запуске в `scripts/main.gd`, функция `_make_sound()`. Отдельные аудиофайлы не требуются. Интерфейс использует встроенный шрифт Godot.

Расширение фракций добавляет ещё шесть оригинальных SVG: огр с дубиной, боевая гончая с ошейником, призрак с рваным плащом, вампир с высоким воротником, деревянная баллиста и вращающиеся лезвия над каменным полом. Иконки нарисованы исходным векторным кодом для этого проекта, без сторонних исходников и лицензионных зависимостей. Орда использует тёплые земляные акценты, Ковен — фиолетовые, Механизмы — голубые.

Каменная архитектура, факелы, лестницы, трон и анимации фигур рисуются кодом в `scripts/dungeon_view.gd`. Изображение стартового меню также создано этим скриптом.

Портрет на троне берётся из выбранного архетипа в `scripts/lord_catalog.gd`, а знамёна окрашиваются в его цвет. Голубое кольцо со щитом обозначает поглощение урона, фиолетовая руна — подготовленное воскрешение, фиолетовые дуги после него — усиление вернувшегося защитника; золотая отметка показывает усиленные удары. Эти элементы только отображают состояние текущего защитника и не управляют боем.

Сторонние наборы графики, шрифтов и звуков для этой версии **не скачивались**. Для замены иконки достаточно отредактировать SVG или изменить поле `icon` соответствующего пресета в `data/rooms/`, `data/heroes/` или `data/items/`.
