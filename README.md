## Развитие

- **Комнаты:** одно «Улучшить» повышает ранг и на порогах **2 / 5 / 15** открывает дерево. Выберите узел, посмотрите эффект и подтвердите. Отложенная ветка открывается той же кнопкой без повторной оплаты.
- **Навыки забега:** души выпадают с героев. Каждый узел общей карты покупается один раз между волнами; дерево открывается по желанию кнопкой «Навыки».
- **Мастерство Лорда:** постоянные ступени **1–5** за Печати Владыки. Дерево показывает будущие усиления и альтернативную способность с мастерства 3. Профиль и существующие покупки сохраняются.

## Как работать с Git

- **`main`** — основная рабочая версия игры.
- **Ветка для задачи**, например `codex/room-synergies`, — место для отдельного изменения. После проверки её изменения объединяются с `main`.
- **Коммит** — сохранённая точка истории с описанием того, что изменено. В коммит должны попадать связанные изменения целиком: новые файлы и изменения старых.
- **Push** — отправка уже созданных коммитов на GitHub. Сам по себе push не сохраняет незакоммиченные файлы.
- **Тег**, например `v1.0.3`, — отметка конкретного коммита как выпущенной версии. Новую ветку на каждый номер версии создавать не требуется.
- **Stash** — временно отложенные изменения. Пока их не вернули и не закоммитили, они не входят в версию на GitHub.

Обычный цикл: отдельная ветка → изменения → проверка → коммит → объединение с `main` → push. Старые ветки `1.0.x` остаются историческими указателями; для следующих релизов используем теги.

## Команда агентов

Ты описываешь задачу в этом проекте, координатор выбирает нужных помощников и собирает результат:

- **Gameplay / Balance** — герои, комнаты как игровые механики, бои, Лорды, таланты и экономика.
- **Dungeon Builder + UI** — размещение комнат, этажи и лестницы на экране, меню, управление и эффекты.
- **QA / Debug / Game Jam Polish** — разбор багов; тестирование по запросу; доводка подсказок, звуков и читаемости по отдельной задаче.
- **Координатор** — требования, распределение файлов, объединение работы и Git/GitHub.

Один файл одновременно правит один исполнитель. Для новой комнаты Gameplay делает правила и данные, Builder/UI — размещение и отображение, а QA разбирает крайние случаи после сборки изменений. Мелкая правка не требует запуска всей команды.

Примеры запросов:

- «Добавь ледяную комнату, раздели механику и интерфейс между агентами».
- «Подключи QA: проверь способности Лордов и повторное начисление душ».
- «Сделай доводку перед джемом: понятнее урон, подсказки и экран поражения».

Общие инструкции находятся в [AGENTS.md](AGENTS.md), три профиля — в [.codex/agents](.codex/agents), лимит в три помощника — в [.codex/config.toml](.codex/config.toml). Модель и разрешения профили наследуют от основной задачи.

Формат настроен по [документации Codex об агентах](https://learn.chatgpt.com/docs/agent-configuration/subagents). Автоматическая загрузка новых профилей текущей открытой сессией не подтверждена. Координатор может уже сейчас прочитать профиль и передать его инструкции подагенту явно; для автоматического обнаружения используй новую сессию в этом проекте. Если проектные настройки не загружаются, проверь доверие к проекту в Codex.
